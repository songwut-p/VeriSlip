## 3. ทดสอบ OCR ครั้งแรก (สลิปจริงที่เบลอข้อมูลอ่อนไหว)

สคริปต์เริ่มต้น `test_ocr.py`:
```python
import pytesseract
from PIL import Image
import os

folder = "test_files"
files = os.listdir(folder)

print(f"เจอไฟล์ทั้งหมด: {files}\n")

for filename in files:
    path = os.path.join(folder, filename)
    print(f"=== กำลังอ่าน: {filename} ===")
    image = Image.open(path)
    text = pytesseract.image_to_string(image, lang="tha+eng")
    print(text)
    print("=" * 40)
```

**ผลลัพธ์:** อ่านวันที่ ("9 ก.ค. 69 12:35 น."), จำนวนเงิน ("30.00 บาท"), ชื่อธนาคาร ("ธ.กสิกรไทย") ได้ถูกต้อง ส่วนบริเวณที่เบลอไว้ (ชื่อ, เลขบัญชี) อ่านผิดตามคาด เพราะพิกเซลถูกทำลายจากการเบลอ

## 4. เรียนรู้ Git พื้นฐาน

### ตั้งค่าตอนแรก (ทำครั้งเดียวต่อเครื่อง)
```bash
git config --global user.name "ชื่อ"
git config --global user.email "อีเมล"
```

### เริ่มต้นโปรเจกต์ (ทำครั้งเดียวต่อโปรเจกต์)
```bash
git init
git branch -m main          # เปลี่ยนชื่อ branch จาก master เป็น main
echo "venv/" > .gitignore   # ไม่ต้อง track โฟลเดอร์ venv
```

### คำสั่งที่ใช้บ่อย
```bash
git status                  # เช็คว่าอะไรเปลี่ยนไปบ้าง (ใช้บ่อยที่สุด)
git add .                    # เพิ่มไฟล์เข้าคิวเตรียม commit
git commit -m "ข้อความอธิบาย"  # บันทึก snapshot
git log                      # ดูประวัติ commit ทั้งหมด
git restore ชื่อไฟล์          # ยกเลิกการแก้ไขที่ยังไม่ได้ commit (คืนกลับเวอร์ชันล่าสุด)
git show รหัส-commit          # ดูของเก่าเฉยๆ ไม่แก้อะไร
git checkout รหัส-commit -- ชื่อไฟล์   # ดึงไฟล์เก่าจาก commit ที่ผ่านมา
git reset --hard รหัส-commit  # ย้อนทั้งโปรเจกต์กลับไปเป็น commit เก่า (ใช้ระวัง)
```

**Commit แรกสำเร็จ:** `54ac8a6` — "Initial commit: OCR test with Tesseract Thai support"

**หมายเหตุสำคัญ:** Git = สมุดบันทึกในเครื่อง (ส่วนตัว, ไม่มีใครเห็น) ส่วน GitHub = เว็บที่เอา git repo ไปโชว์เป็นพอร์ตโฟลิโอให้คนอื่นดู (คนละเรื่องกัน แต่ทำงานคู่กัน)

## 6. ทดลอง Image Preprocessing (Grayscale + Contrast)

เพิ่มขั้นตอนก่อนส่งภาพเข้า OCR:
```python
image = image.convert("L")                          # แปลงเป็นขาวดำ
enhancer = ImageEnhance.Contrast(image)
image = enhancer.enhance(1.5)                        # เพิ่มความคมชัด
```

### ผลการทดลองเปรียบเทียบ

| จุดที่วัด | ไม่ preprocess | contrast 2.0 | contrast 1.5 |
|---|---|---|---|
| ชื่อคน/ธนาคาร/เลขบัญชี | (ยังไม่ทดสอบ) | แม่นมาก | แม่นมาก |
| เลขที่รายการ (ยาว 18 หลัก) | (ยังไม่ทดสอบ) | ถูกต้อง | ถูกต้อง |
| "ชำระเงินสำเร็จ" (หัวข้อตัวหนา) | (ยังไม่ทดสอบ) | อ่านไม่ออกเลย | ใกล้เคียงขึ้นแต่ยังไม่สมบูรณ์ |
| "จำนวน:" | (ยังไม่ทดสอบ) | ผิดเป็น "Usa" | ถูกต้อง แต่ "500.00 บาท" กลายเป็น "uses 500.00 บาท" |

### 🔑 Insight สำคัญที่ค้นพบ

**ทำไม contrast enhancement ถึงทำร้ายตัวหนา แต่ช่วยตัวบาง:**

- การเพิ่ม contrast คือการดันพิกเซลเข้มให้เข้มขึ้น และพิกเซลอ่อนให้อ่อนลง เพื่อแยกตัวอักษรออกจากพื้นหลังให้ชัดขึ้น
- **ตัวอักษรบาง (regular):** เส้นห่างกันพอสมควร เพิ่ม contrast แล้วยังแยกจากกันชัดเจน → อ่านง่ายขึ้น
- **ตัวอักษรหนา (bold):** เส้นชิดกันอยู่แล้ว พิกเซลตรงกลางระหว่างเส้นเป็นสีเทา พอ contrast แรงจะถูกดันให้กลายเป็นดำ (แทนที่จะเป็นขาว) → เส้นสองเส้นเชื่อมติดกันเป็นก้อนดำ → Tesseract อ่านรูปทรงตัวอักษรไม่ออก
- เปรียบเทียบ: เหมือนปากกาหมึกซึมระบายทับตัวหนังสือ — ตัวเขียนห่างยังอ่านออก แต่ตัวเขียนติดกันจะกลายเป็นหมึกเลอะอ่านไม่ออก

**สรุป:** ไม่มีค่า contrast ที่ "ดีที่สุดตายตัว" เพราะภาพสลิปมีทั้งตัวหนา (หัวข้อ) และตัวบาง (เนื้อหา) ปนกันในภาพเดียว การปรับแบบเดียวกันทั้งภาพ (global) ต้อง "แลก" เสมอ

### แนวทางแก้ไขที่วางแผนไว้ (ยังไม่ได้ลอง)
1. **Adaptive thresholding** — ปรับ contrast ไม่เท่ากันทุกจุด โดยดูพิกเซลรอบข้าง (มีในไลบรารี OpenCV)
2. **แบ่งโซนประมวลผล** — ตัดภาพเป็นส่วนหัวข้อ vs เนื้อหา แล้ว preprocess แยกกันคนละค่า
3. **ทดสอบไม่ preprocess เลย** เทียบกับที่ preprocess ไว้ (ค้างไว้ ยังไม่ได้ทำ)
